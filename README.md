## Note on Code Execution

All solutions have been collected and organized in a single Jupyter Notebook (`solutions.ipynb`) for readability and ease of navigation.

The code cells contain the original Python solutions as submitted and executed on HackerRank, without modifications.

These solutions have not been adapted for direct execution in a Jupyter Notebook environment, as the homework instructions do not explicitly require such adaptation.

The original HackerRank input/output handling and execution structure have therefore been preserved.

I approached each exercise independently and attempted to develop my own solution before seeking any assistance.

When I encountered difficulties, I occasionally used Large Language Models (LLMs) as learning and debugging tools. Rather than requesting complete solutions, I asked for guidance on how to approach a problem, how to reason through the underlying logic, or how to understand and resolve error messages.

The purpose of using LLMs was to support my understanding and problem-solving process, rather than to replace my own work.
